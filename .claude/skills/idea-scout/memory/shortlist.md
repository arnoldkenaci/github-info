## Best candidates for the next deep-research batch

1. **I-064 cheese moulds and shrink bags for small dairies (84).** It has repeat consumables and a clear trigger:
   AKU is pushing 253 dairy operators to EU standards. First phone 3 dairies in Gjirokaster/Korca and ask where they
   buy moulds and bags. If Italian or Greek reps already serve them, the score drops to ~76. *With host kits:* no shared
   buyers or supplier. Demand runs all year, so it does not depend on the summer host season.
2. **I-060 berry punnets (83), screened with I-050 crates (78) as a "Fier grower packaging" bundle.** Same growers and
   exporters, same Turkish packaging exporters, one pallet. First phone Fragoland and 2 Fier packaging/agro shops about
   punnet supply. *With host kits:* no shared buyers. Punnets sell March to June, before the host peak, and could share
   Turkish freight.
3. **I-036 beekeeping equipment (79).** It is the only one of the old top 3 whose gap survived the Megateksa check. Screen
   the I-040 jars alongside it again, now at 73 because Megateksa sells bottles and jars. A specialist's edge would be
   honey-jar sizes, lids and case delivery to co-ops. *With host kits:* no shared buyers; oil bottles sell November
   to January, the host kits' quiet winter.

Runner-up: I-061 scaffold netting (78, gap checked as available). Its demand comes from the same builders as I-044
doors. I-041 peshtemal (74) is still the most natural host-kit add-on (same Denizli mills, same EUR.1 pallet).

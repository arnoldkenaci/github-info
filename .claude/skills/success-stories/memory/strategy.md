## Learned rules

1. **Skip supplier/forwarder blogs written as first-person "I lost $X" stories**: anonymous content marketing. (run 1)
2. **Bot-checked pages** (Indie Hackers, YourStory, usaid.gov, PhocusWire): run one follow-up WebSearch on the exact
   title, record details as "read via search index", never fill gaps by guessing. (run 1)
3. **Generic "COD refusal rate" queries return vendor marketing**; search operator-written pieces instead. (run 1, confirmed run 2 for Romania)
4. **Albanian-language failure queries return statistics, not stories**; use named businesses, founder interviews and
   Balkan media; keep 1-2 Albanian queries per run as exploration. (run 1)
5. **Cap at ~15 searches per run and fetch only pages with a named person/business.** (run 1; run 2 kept to 12 searches + page fetches)
6. **Prefer list pages and transcripts over show notes**: Failory's failure list and Side Hustle School transcripts gave
   6 detailed stories in run 2 with no extra searches. (run 2)
7. **Buyer-behaviour threads** (hosts describing their own buying) are logged as stories with model "other", outcome
   "mixed" and business starting "Buyer evidence:"; they may support lessons about demand but never count as seller
   successes/failures. (run 2)
8. **Skip VC-funded or quick-commerce stories (relevance ≤2)** unless the lesson is about a small seller (skipped Pop Market, Lidyana). (run 2)
9. **Stylised, first-name-only podcast stories are "anecdote"** and may never be the only evidence for a lesson (S-018). (run 2)
10. **One article can hold several stories**: dedupe on business+person; the same URL is allowed for different businesses (S-019/S-020). (run 2)
11. **Failures still skew to US/UK.** Run 3 must spend at least 3 searches on Balkan/Albanian failures through K2.0, UN Women,
    local-language named-business queries, not on Failory. (run 2)
12. **Check the source URL loads before logging a story** (`curl -s -o /dev/null -w "%{http_code}"`). A story whose
    only page is dead (Loomed NOLA, 404) is not logged even if the search index still shows its text. (run 3)
13. **Balkan failure stories surface as local-language "confession" news** (Serbian "ispovest", news retelling Reddit
    posts), not through English e-commerce queries, K2.0 or UN Women. Run 4 spends at least 3 searches on
    sr/sq/mk confession-style queries naming a shop type (online shop, Instagram shop, boutique, importer). (run 3)
14. **Low yield in run 3 (1 story with relevance 4-5).** Run 4 must: (a) stop after 2 zero-yield searches on the same
    gap and switch gap; (b) put at least 50% of searches in local languages (sq, sr, mk, tr, fr for managers);
    (c) keep 1 search for a snowball lead from the previous run (Bohochic Dreamer, La Conciergerie). (run 3)
15. **Side Hustle School is a US side-hustle source**: max 1 query per run, and only keep episodes about supplier,
    wholesale/B2B or import problems; 7 of 9 transcripts read in run 3 were irrelevant. (run 3)
16. **Respect the search cap.** Run 3 used 21 searches (cap ~15) chasing dead ends; count searches as you go and stop
    a line of inquiry after 2 empty results. (run 3)
